# Real-Time-RFID-Authentication
      My project focuses on building an intelligent "Smart Door" system. Instead of just using a simple key or a standard code, I wanted to create a system that knows who is entering and when they are trying to enter.
          The system uses an ESP8266 microcontroller and an RFID reader to scan user tags. It then checks the time online (using NTP) to decide if that specific person is allowed in at that specific hour.
     Finally, it logs everything—successes and failures—to a Google Sheet so I can see a colourful, real-time history of who accessed the room.
